## Key Commands

```bash
# Pre-commit (MUST run before finishing any task)
pre-commit run --all-files

# Root Taskfile (task --list for the full list)
task init                # Install system dependencies (Homebrew)
task apply-all           # base first, then the samples in parallel (expensive: ask first)
task destroy-all         # samples first, then base
task test-all            # Offline Terraform tests of every sample (mock providers, no credentials)
task review              # pre-commit run --all-files

# Per sample (cd samples/<name>): task init | plan | apply | destroy | test | e2e | cyber-scan
# `task --list` inside the sample shows what it really offers (not all samples have e2e).
```

`TFDOCS.md` is generated by the `terraform_docs` pre-commit hook: never edit it by hand.

> [!NOTE]
> Each Terraform root commits its `.terraform.lock.hcl` (provider hashes for `linux_amd64`, `darwin_arm64`, `darwin_amd64`), and CI and the `terraform_validate` hook run `init -lockfile=readonly`. A stale local `.terraform/` (ignored by git) is fixed with a plain `terraform init` in the sample root. `terraform init -upgrade` rewrites the tracked lock file: use it only to update providers on purpose, then run `terraform providers lock -platform=linux_amd64 -platform=darwin_arm64 -platform=darwin_amd64` and commit the lock (Renovate maintains it otherwise).

## Coding Standards

- **Terraform**: Use official modules first (`terraform-google-modules`, `terraform-aws-modules`). Pin all versions. Split by service (`iam.tf`, `network.tf`). Add `validation {}` blocks.
- **Taskfile**: Version 3. Centralized vars. Explicit `desc:`. Use `deps:` not chained cmds.
- **Security**: Private subnets by default. Least privilege IAM. Encryption at rest. Gitleaks in pre-commit.
- **Commits**: Conventional commits (`feat:`, `fix:`, `chore:`, `docs:`, `refactor:`, `test:`), enforced by the `conventional-pre-commit` `commit-msg` hook.
- **Dependencies**: pin versions (Terraform modules/providers `~>` with the committed `.terraform.lock.hcl` fixing the exact provider builds, container base images by digest, `==` for pip, a pinned Spring Boot parent for Maven); a CVE fix is a dedicated `fix(deps):` commit.

## GCP Resource Labeling Constraint

- All Terraform configurations MUST define `default_labels` at the Google provider level.
- The `project` label value MUST be prefixed with `gcp-samples_` (e.g., `gcp-samples_base`). Slashes (`/`) are strictly forbidden by GCP labeling constraints; use underscores (`_`).

## CI (GitHub Actions)

Follows the global `github-workflows` rule. Workflows run on **`pull_request` only** (never `push`), without cloud credentials: `build-<sample>.yml` (via the reusable `_build-sample.yml`), `check-quality.yml` (pre-commit) and `check-cyber.yml` (KICS, Trivy). Shared configs: `.tflint.hcl`, `kics.config`, `trivy.yaml`, `.trivyignore.yaml` (scoped and justified exceptions only). Validate with `actionlint` and `gh pr checks`; merge only when every check is green.

## Standard Workflow

```

2. BUILD    → Apply changes respecting existing patterns
3. VERIFY   → pre-commit run --all-files (fix all issues)
```
